02 / RESPONSE FIELD INVENTORY

What the saved responses contain

A field can be populated even when the returned evidence is irrelevant or incorrect. These counts describe response structure; each returned item is still unverified.

Results with a field present

100 saved results per system · raw counts · no accuracy score

“100 present” means 100 records contain that field. It does not mean 100 correct answers. Correctness, relevance, original visual identity, and primary-source provenance have not been evaluated.

Counts apply to normalized responses, so adapter behavior affects which fields appear. A zero means the field is absent from these records; a figure URL or descriptive snippet may still point to useful evidence. Absence is not a verified retrieval failure.

How field presence is counted

Document = source document URL; visual = visual URL or SHA-256; publisher = publisher label; location = a structured location object; data = a dataset reference carrying a URL, hash, or identifier. References are not checked for accessibility, relevance, correctness, or source ownership. A figure-like URL does not automatically become a verified visual or location.

06 / METHODOLOGY & PROVENANCE

A report you can trace.

Every displayed observation is derived from the archived diagnostic responses. No paid searches were made to produce this report.

Query set & invocation

Ten pre-existing development candidates, one each in economics, finance, energy, AI, climate, demographics, labor, housing, science, and policy. Each system received the same query text and returned ten ranked results. No shared fetch, hybrid enrichment, or LLM judging was performed. Google / Serper was skipped because credentials were missing.

Quality & uncertainty

This run has no accepted gold or independent human reviews. Full Support, component recall, MRR, paired quality differences, and quality confidence intervals are unavailable. Future scored comparisons should use matching benchmark versions and protocols, and resample by evidence family for 95% intervals. No pooled “ultimate” baseline is defined for this diagnostic.

Scope & limitations

Evidence8 used a local corpus and API. The query candidates predate the index snapshot, so this is not a pre-authoring freeze attestation. Corpus membership is unknown. Nine queries target charts; one targets a multi-panel figure. There is one run, no longitudinal history, and insufficient reviewed evidence for a provider quality ranking.

Archived integrity

The saved run manifest records successful raw-artifact and receipt integrity checks and identical offline normalization for all 30 response cells. This report derives its figures from those saved normalized responses; it does not repeat that integrity audit. The downloadable report data includes each response file's SHA-256 as read when this report was generated.

Run identity, hashes & source artifacts

Design reference: NEEDLE. Its presentation inspired the legible tables, latency range plot and audit trail. VESSEL's metrics follow its own evidence-bundle definitions.
